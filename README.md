# 高中生成绩分析工具 2.0

功能：
- 手机端优先
- 自定义科目与每科满分
- 自动计算我的总分和平均分
- 按“成绩 ÷ 满分”分析薄弱科目
- 导入 XLSX、XLS、CSV 成绩表
- 自动计算导入表格中每位同学的总分并排名
- 输入自己的姓名查看排名与超过比例
- 不需要登录或数据库
- 我的科目与成绩保存于浏览器 localStorage

Excel 要求：
- 读取第一张工作表
- 第一行是表头
- 至少有姓名列，或第一列可作为姓名
- 科目列名称要与网页中的科目名称一致
- 空白成绩不会计入该同学总分

注意：Excel 解析库通过 SheetJS CDN 加载，因此导入 Excel 时需要网络连接；成绩文件本身在浏览器本地解析，不上传到本项目的服务器。

文件说明：
- index.html：网页结构
- style.css：手机端样式
- script.js：成绩计算、薄弱科目分析、Excel 导入和排名
- README.md：使用说明
