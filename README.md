# 班主任班级成绩分析系统 4.0

## 主要功能
- 单班成绩 Excel/CSV 导入
- 自动计算总分与总分竞争排名（同分同名次）
- 全班成绩表：姓名、总分、所有科目；可按总分或任意科目排序
- 学生姓名查询：总分、班级排名、每科成绩、满分、得分率、科目排名、优势/薄弱科目
- 各科平均分、平均得分率、最高分、最低分
- 总分分段统计
- 重点关注学生筛选
- 可配置科目与满分

## Excel格式
第一行是表头，必须有姓名列（姓名/学生姓名/名字/学生均可），科目列名称与网页中的科目名称一致。系统读取第一张工作表。

示例：姓名 | 语文 | 数学 | 英语 | 物理 | 化学

## 排名规则
总分和单科排名均为竞争排名：1、2、2、4。缺考/空白成绩不参与该科排名。

## 隐私
本页面代码不包含成绩上传接口；Excel 在浏览器内解析。Excel 解析库从 SheetJS CDN 加载，因此首次使用导入功能需要网络。


### 4.1 修复说明

- 同分学生获得相同名次，下一名跳过相应名次。
